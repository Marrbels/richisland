# Audio credits

Every sound in Rich IsLand is free-licensed third-party audio: CC0 (public domain) or CC BY
(attribution required — see below). Licenses were checked on each asset's own page. The files here
are edited versions (cut, layered, levelled, re-encoded to WebM/Opus + MP3).

Rebuild everything from the original downloads with `node tools/assets/audio/build.mjs`; the
recipe for each sound is in `tools/assets/audio/sources.mjs`. This file is generated — edit the
recipe, not this file.
